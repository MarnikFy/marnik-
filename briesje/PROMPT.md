# Startprompt

De werkregels staan in `CLAUDE.md` en worden automatisch gelezen. Start een nieuwe Claude Code sessie op de repo `briesje` en plak dit, met het juiste fasenummer:

---

Werk aan fase [NUMMER] uit PLAN.md. Lees eerst PLAN.md en CLAUDE.md. Vertel me in een paar regels wat je gaat opleveren en hoe je het controleert. Heb je vragen die de inhoud of uitstraling bepalen, stel ze voordat je bouwt.
