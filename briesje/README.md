# Briesje

Website en webshop van Briesje, met een 3D boek als hero.

| Bestand | Waarvoor |
|---|---|
| `PLAN.md` | Wat we bouwen, waarom, en in welke fases |
| `CLAUDE.md` | Werkregels voor Claude Code, die automatisch gelezen worden |
| `PROMPT.md` | De zin waarmee je een bouwsessie start |
| `bestanden/` | Alle bronmateriaal: verhalen, oude site, foto's, productinfo |

## Repo aanmaken (eenmalig)

1. Ga naar github.com/new.
2. Vul bij naam `briesje` in, kies **Private**, en vink niets aan (geen README, geen .gitignore, geen licentie). Klik op "Create repository".
3. Ga naar github.com/settings/installations, klik bij "Claude" op Configure. Staat daar "Only select repositories", voeg `briesje` toe en sla op.
4. Laat het Claude weten. Die zet dit plan erin.
